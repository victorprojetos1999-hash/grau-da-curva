# Grau da Curva

Calcula o grau de curvas de tubo pela medida das costas ou da frente (com raio e diâmetro), com tabelas de tubos SCH (ASME B36.10M / B36.19M) e raios de curvas (ASME B16.9).

Funciona sem internet e pode ser instalado no celular e no computador.

**Abrir o app:** https://victorprojetos1999-hash.github.io/grau-da-curva/
